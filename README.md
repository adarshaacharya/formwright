# Formwright Monorepo

This repository contains the Formwright schema-driven form engine and related packages.

## Workspace Layout

- `packages/contract`
- `packages/core`
- `packages/react-rhf`
- `packages/renderers-default`
- `packages/plugins-basic`
- `packages/plugins-async`
- `apps/playground`
- `apps/docs-demo`

## Commands

- `pnpm install`
- `pnpm build`
- `pnpm dev`
- `pnpm lint`
- `pnpm test`
- `pnpm typecheck`
- `pnpm clean`
