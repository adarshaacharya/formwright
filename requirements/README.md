# Form Builder Requirements

This folder captures the architecture requirements discussed for a dynamic, schema-driven form builder powered by React Hook Form.

The design goals are:

- backend-driven form definitions
- headless-first rendering
- strong extensibility through plugins and overrides
- dynamic layout and behavior
- clean separation between schema, runtime, and UI
