# API Reference: @formwright/core

Public API comes from `packages/core/src/index.ts`.

## Primary Exports

- `createFormRuntime`
- `createPluginRegistry`
- `DuplicatePluginError`
- `FormRuntime` and related runtime/plugin types

## `createFormRuntime`

```ts
createFormRuntime(input: CreateFormRuntimeInput): FormRuntime
```

Creates a runtime from a form definition, optional runtime context, and optional plugins.
